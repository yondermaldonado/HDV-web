Sobre mí

Soy estudiante de desarrollo de software con base sólida en Python, JavaScript y control de versiones con Git/GitHub. Tengo experiencia real construyendo sistemas de automatización con IA y aplicaciones web completas, desde la lógica de negocio hasta la interfaz de usuario.

Soy una persona organizada y metódica: cuando un problema es complejo, lo divido en partes manejables y las resuelvo una por una sin perder de vista el objetivo general. Me adapto con facilidad a equipos de trabajo y disfruto tanto programar como comunicar ideas técnicas de forma clara.

Fuera del código, me interesa entender cómo la inteligencia artificial puede resolver problemas cotidianos y reales — no como una moda, sino como una herramienta más dentro de un sistema bien diseñado.

Cómo trabajo

Sea un flujo de automatización o una aplicación web, sigo el mismo orden para no perder de vista el objetivo mientras resuelvo el detalle técnico.

  1. Entender el problema real

    Antes de escribir código, defino qué necesita resolver la persona que va a usar el sistema, no solo qué pide el enunciado.

  2. Diseñar la estructura

    Divido el problema en partes manejables: qué datos entran, qué transforma el sistema y qué sale, antes de tocar la implementación.

  3. Construir y probar

    Implemento por partes y pruebo cada una con datos reales, no solo con el caso ideal.

  4. Iterar con retroalimentación

    Ajusto según lo que falla o lo que un usuario real señala, y documento los cambios para que el sistema siga siendo mantenible.
